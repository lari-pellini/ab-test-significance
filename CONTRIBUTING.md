# Contributing / Como contribuir

Thanks for your interest! 💜 / Obrigada pelo interesse! 💜

This is a small experiment about SEO, marketing and UX on the web, and contributions of every size are welcome — code, docs, translations, bug reports or ideas.

Este é um pequeno experimento sobre SEO, marketing e UX na web, e contribuições de qualquer tamanho são bem-vindas — código, documentação, traduções, bugs ou ideias.

## How to / Como

1. Look for issues labelled **good first issue** or open a new one describing your idea. / Procure issues com a etiqueta **good first issue** ou abra uma nova descrevendo sua ideia.
2. Fork the repo and create a branch. / Faça um fork e crie uma branch.
3. Keep the project dependency-free when possible and add a test for new behaviour. / Mantenha o projeto sem dependências sempre que possível e adicione um teste para o novo comportamento.
4. Open a pull request explaining *what* changed and *why*. / Abra um pull request explicando *o que* mudou e *por quê*.

Issues and pull requests can be written in **English or Portuguese**. / Issues e PRs podem ser escritos em **inglês ou português**.

Be kind and assume good intent. / Seja gentil e presuma boa intenção.
